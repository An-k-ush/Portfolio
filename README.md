# Portfolio Website

Static portfolio website built with **HTML, CSS, and JavaScript**.

## Pages
- `index.html` — personal profile, skills, education, project, achievements
- `blog.html` — blog listing page
- `builder.html` — drag-and-drop page builder with localStorage persistence

## Run locally
From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
